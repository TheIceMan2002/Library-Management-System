# Library Management  System
A Campus Library Management System built with C# Windows Forms and Microsoft SQL Server. Developed for CPTR 319 at Southern Adventist University.

## Features
-Staff dashboard: manage books, memebers, checkouts, and returns
-Automated fine calculation via SQL stored procedure
- 4 database triggers for automatic copy status updates
- Overdue loans report via SQL VIEW
- Member portal: browse catalog, reserve books, view loan history and fines

## Tech Stack
- C# / .NET 8 / Windows Forms
- Microsoft SQL Server Express
- System.Data.SqlClient
